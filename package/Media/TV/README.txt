Put your Rabbit Ears channels here.

  A video file              = one channel
  A folder of videos        = one channel
  Show folders in a channel = the channel rotates between the shows,
                              one episode at a time, in episode order

Start a name with a number to choose the channel: "07 Cartoons".
Old commercials go in the Commercials folder.
Convert videos with vhsify first: https://github.com/snyderman3000/rabbitears
